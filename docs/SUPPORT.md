# Support JARVIS

JARVIS is an independent project being built publicly by Saviour, with GPT-5.6 Luna as the AI development partner.

The goal is to build a useful AI platform while documenting the real engineering journey: the successes, failures, fixes and lessons.

## Ways to support

You do not need to spend money to help.

### Free support

- ⭐ Star this repository
- 🔁 Share JARVIS with someone interested in AI or software
- 🧪 Try the public demo when available
- 🐛 Report reproducible bugs
- 💡 Suggest useful features
- 📖 Improve documentation
- 💻 Contribute code or tests
- 🎥 Share a JARVIS progress video

### Hardware and infrastructure support

The project is being developed with limited personal hardware. If you or an organization genuinely wants to help the project grow, useful support can include:

- Development laptop or computer
- Development phone
- Cloud hosting credits
- AI/API credits
- Storage resources
- Testing equipment

Hardware or financial support is never required to participate.

## What support helps build

Support can help move JARVIS toward:

- Persistent long-term memory
- Reliable background workers
- Image and video generation
- Voice capabilities
- Business automation
- Developer tools
- Security and recovery systems
- Public integrations
- Better testing and infrastructure

## Transparency

This project is being built in public. Support does not buy ownership of the project, guaranteed features, or guaranteed results.

Development updates should be documented in the [JARVIS Journey](JOURNEY.md), and claims about completed features should be based on verified work.
