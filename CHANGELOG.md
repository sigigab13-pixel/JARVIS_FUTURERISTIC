# Changelog

All notable JARVIS changes are documented here.

The project is currently in active development, so this changelog focuses on major milestones rather than every individual source change.

- JARVIS Empire Command deployment foundation
- Central orchestration contracts
- Capability/tool registry foundation
- Realtime infrastructure
- Voice Engine panel
- YouTube OAuth connection flow
- Forest content-production module
- NEXORA simulation modules
- Progressive Web App assets
- Public GitHub source repository
- Deployment-side secret management
- Professional project documentation

### Security

- Sensitive service credentials remain in deployment secrets rather than public source.
- Public source contains secret references/configuration names, not credential values.
